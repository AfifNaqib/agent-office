# Spike S5: Cloudflare Access on workers.dev with path bypass

**Result (2026-10-25): PASS. Decision D3 (second hostname) is not needed.** Tested on the spike Worker `<spike>` (`spikes/s1`, branch `spike/s1`), team domain `<team>.cloudflareaccess.com`, free Zero Trust plan.

## Setup (what the PO did)
1. Workers & Pages → <spike> → Settings → Domains & Routes → workers.dev → Enable Cloudflare Access, scope **All traffic** (main URL and previews). This auto-creates the Access app "<spike> - Cloudflare Workers" (policy: Cloudflare account members).
2. Zero Trust → Access → Applications → Create new application → Self-hosted, name `<spike>-ingest`, two public hostnames `<spike>.<your-subdomain>.workers.dev/ingest` and `/bridge`, policy `bypass` = Bypass + Everyone, session 24 h.
